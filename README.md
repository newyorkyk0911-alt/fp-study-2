# FP Study 2 v0.3

`index.html` を静的配信して使用します。外部ライブラリへの実行時依存はありません。

- 既存180問と0始まりのID、localStorageキー `fp-study-2-v1` を維持。
- 通常演習は全分野で一巡するまで同じ問題を再出題しません。一巡の最後は10問未満になる場合があります。分野を完了した場合は別分野で進めます。解答時に進捗を保存し、中断後も未解答から選び直します。○×と4択は出題進捗を共有します。
- v0.2履歴は初回起動時に読み取り、過去に解答したIDを現在の一巡の出題済みとして扱います。旧履歴には一巡の区切りがないため、それ以前の周回数は推測しません。
- 通常演習の結果表示から3秒後に誤答を自動復習します。ホームへ移動すると中止できます。復習後は自動開始しません。復習は一巡進捗と別扱いです。正解すると復習待ちを解除します。
- 直近正答率は直近20解答、初回正答率は問題ごとの最初の解答（形式共通）。誤答回数は累計です。分野別・問題別に表示します。
- `questionMetadata[id]` で難易度・出典・法令基準日を管理します。既存問題の裏付けは未検証のため全て `null`（画面では未確認）。確認できた場合だけ `difficulty`、`source`、`lawAsOf` に値を設定してください。問題本文中の年の記載だけでは法令基準日を確定しません。
- JSONはv0.2の記録そのもの、v0.3のアプリ名・バージョンを含む形式に対応。検証後にプレビューし、確認ダイアログで置換復元します。復元前に現在の記録を書き出してください。マージ復元ではありません。不正なJSONは保存しません。10MBを上限とします。
- 日付・カレンダー・連続日数はJST固定。連続日数は今日、今日未学習なら昨日を起点に計算。最長日数も表示します。

## テスト

Node.jsとPlaywrightを用意して実行します。

```sh
npm install --no-save playwright
npx playwright install chromium webkit
node tests/v03.cjs
```

Chromium / WebKitのiPhone 13相当画面（端末タイムゾーンは米国）で、履歴移行、180問一巡、復習、分析、未確認メタデータ、JSON読み込み・復元・書き出し、破損データ保護、JST境界、閏年と連続日数を検証します。実機iPhone Safariの確認は別途必要です。
